# delta 移植分析与可借鉴功能清单

> 调研日期：2026-08-26 ｜ 调研对象：`dandavison/delta` v0.19.2（Rust, MIT, 31.8k stars）↔ 本仓库 chrome-md-editor v1.9.10
> 调研方式：gh 直读上游源码（Cargo.toml / ARCHITECTURE.md / align.rs / edits.rs / paint.rs / navigate.rs / side_by_side.rs / draw.rs）+ 本地图谱与本仓源码交叉核对
> 结论效力：本文为该议题的**单一权威结论**，取代此前对话中的口头分析；后续移植讨论以本文为基线。

## 一、问题一裁决：能否将 delta 代码/二进制「包裹·镶合·添加」进本仓库？

**结论：二进制或整体镶合不可取，价值为零；正确路线是「按模块移植算法与设计」，且核心算法已完成移植。**

三条硬理由：

1. **构建目标不兼容**：delta 的 `Cargo.toml` 仅有 `[[bin]]`（name="delta", path="src/main.rs"），**没有 `[lib]` target**——它从未被设计为库。作为 Rust 库镶合进 Tauri 桌面端需自行改造 crate 结构并剥离 bat / syntect / less 全套终端依赖，工程量远超收益。
2. **输入输出两端错位**：
   - 输入端：delta 消费的是 **unified diff 文本流**（git diff/blame/grep 的 stdout）。它**不做 .md/.txt 行间差异计算**——行级配对由 git 完成，delta 只做 subhunk 内 minus/plus 行的同源行配对与行内 token 对齐。本仓库对比任意两份文档，须先用 jsdiff/@codemirror/merge 生成 unified diff 再喂给 delta，绕一圈回到原点。
   - 输出端：delta 输出 **ANSI 终端转义码**并写入子进程 `less` 的 stdin（ARCHITECTURE.md 明示）。浏览器无法渲染 ANSI，复用前还得再写一层 ANSI→HTML 解析器，负收益。
3. **运行环境硬约束**：浏览器扩展无法分发/调用外部 exe；Tauri 桌面端理论上可 sidecar 二进制，但仅桌面版受益、扩展主体完全不受益，且 delta 对 Markdown 无任何语义处理能力，收益为零。

## 二、重大事实：核心算法已完成移植（勿重复移植）

**`src/compare/delta-align.js`（726 行）已是 delta `align.rs` + `edits.rs` 的 MIT 授权 JS 移植版**，文件头完整记载移植来源与 7 条适配改动：

| 上游 | 本仓库 | 说明 |
|---|---|---|
| `align.rs` Needleman-Wunsch/Wagner-Fischer 编辑距离表（代价常量 DELETION_COST=2 / INSERTION_COST=2 / INITIAL_MISMATCH_PENALTY=1） | `delta-align.js:59-68` 同名常量逐一对应 | 含 run-length 合并与回溯 |

## 三、可简单修改后移植的功能清单

### A 档：直接移植（delta 有、本仓库无）

| # | 上游来源 | 功能 | 落点与工作量 |
|---|---|---|---|
| A1 | `utils/tabs.rs` + `features/diff_highlight.rs` | **空白错误高亮**：行尾空白、tab 缩进、tab 前空格混排检测 | 几个正则 + CodeMirror Decoration mark，半天级。对 .md 尤其实用——行尾双空格是 Markdown 强制换行语义，误删即坏；编辑期可见比发布后返工强 |
| A2 | `handlers/hunk_header.rs` | @@ 头显示所属函数上下文 | Markdown 场景改造成**显示所属 `#` 章节标题**（向上扫描最近 ATX 标题），注入 `src/compare-diff-export.js:22` buildDiffText 的 @@ 行与 location-pane 提示，导出报告可读性显著增强 |
| A3 | `handlers/diff_stat.rs` | **变更统计概览**（+N/-N 条形统计） | 本仓库实测无对应物（grep addedCount/insertions 零命中）。基于 chunks 数组即可聚合：总增删行数 + 每 chunk 增删分布条。挂 compare 视图顶栏 |
| A4 | `paint.rs:391 mark_empty_line` + right_fill 机制 | **双栏空行填充标记**：一侧独属行的对侧补带样式的空位标记，视觉锚定配对关系 | MergeView 默认对侧留白无标记；加一个 Decoration.replace/widget 即可，改善 N↔M 块阅读定位 |
| A5 | `features/diff_highlight.rs` keep-plus-minus-markers | 行内保留 +/- 标记符 | 小改动；配合导出的 unified diff 对照阅读时有用 |

### B 档：本仓库已有、但稳定性/体验弱于 delta，需加固

| # | 差距点 | 本仓库现状（证据） | delta 做法 | 加固方向 |
|---|---|---|---|---|
| B1 | **块间导航的标记与计数反馈** | 已有 navNext/navPrev + 快捷键（`compare.js:2004-2010`，B/] 与 Shift+B/[），location-pane 点击也可跳 | navigate 特性提供 hunk-label "•"/file-modified-label "Δ" 标记体系，跳转目标一眼可辨 | 跳转时高亮当前块 + 显示「第 n/N 块」计数徽标；超屏块先滚动再闪烁定位框 |
| B2 | **同源判定的 emph 分层样式** | delta-align 配对成功即统一词级高亮，未配对行与配对行的非改动段同底色 | `paint.rs:550` 仅 `line_has_homolog=true` 才启用 emph 强调样式，未配对行整行平铺色——**防止把整行重写误读成局部修改** | 引入 lines_have_homolog 布尔层：配对行改动段用强调色，未配对行整行用弱底色。纯 CSS class 区分，改动小、误读率显著下降 |
| B3 | **尾随空白独立分段** | 词级 diff 把行尾空白并入相邻 token | `edits.rs:110 get_contents_before_trailing_whitespace` 把尾随空白单独切出（为 whitespace 高亮铺路） | 与 A1 联动：在 tokenize 后处理阶段切出尾随空白段，单独打标 |
| B4 | **超长行折行的对齐保持** | CodeMirror 自带软折行，折行后双栏行高可能失配（scroll-sync 依赖 MergeView 共享滚动盒兜底，见 scroll-box.js 注释） | `wrapping.rs`(42KB)+`side_by_side.rs` has_long_lines 先探测再决定折行策略，保证折行后左右仍逐行对齐 | MergeView 场景下对超长 chunk 行做「等高钳制 + 行内省略」或按 delta 思路预探测 has_long_lines 决定是否启用 word-wrap，避免两栏行高漂移 |
| B5 | **样式主题化配置面** | theme-presets 为内置预设，用户不可自定义对比配色 | `parse_style.rs`/`options/theme.rs` 的 `*-style` 键值 DSL（如 `minus-emph-style = normal "#901011"`） | 借鉴其键值模型做「对比配色自定义面板」：键→CSS class 映射表 + 预设导入导出。属设计借鉴，量级中等 |

### C 档：不建议移植（附理由）

| 上游模块 | 理由 |
|---|---|
| `ansi/*`、`utils/bat/*`（less pager、终端色板） | 纯终端生态，浏览器无用武之地 |
| `wrapping.rs` 折行排版主体 | 终端字符排版刚需；浏览器由 DOM 排版引擎承担，仅借鉴 B4 的探测思路即可 |
| `features/hyperlinks.rs`（OSC8 终端超链接）、`handlers/grep.rs`/`ripgrep_json.rs`/`blame.rs` | 服务于 git/blame/grep 输入流，与双栏文档对比场景无关 |
| `subcommands/parse_ansi.rs` 等 | ANSI 解析工具集，仅在走二进制包裹路线时才需要——该路线已被否决 |
| syntect 语法高亮 | 本仓库已有 highlight.js 覆盖同一需求且更轻 |

### 反超项（本仓库独有，无需向 delta 取经）

移动块检测连线（move-detection/move-connectors/move-decorations）、三栏 Base/Yours/Theirs 合并视图、图片对比（compare-images）、位置缩略导航条（location-pane 色块 + 移动弧线）、块级采纳/回退合并操作。这些是 delta 作为只读终端 pager 架构上不可能具备的能力。

## 四、实施建议（优先级）

1. **第一批（小改动高回报）**：A1 空白高亮 → B2 emph 分层样式 → B1 导航计数徽标。
2. **第二批（体验完善）**：A4 空行填充标记 → A3 变更统计概览 → B3 尾随空白分段。
3. **第三批（按需）**：A2 章节上下文注入导出 → B5 自定义配色 → B4 折行对齐加固。
4. 每批完成后按项目惯例走「实现 → 全面检查 → 复检 → 真机点检」闭环，移植代码文件头照 delta-align.js 惯例标注上游来源与适配改动，MIT 许可证与版权归属（Copyright (c) Dan Davison）随文件保留。
