# 测试方案：工具栏与预览重构（feat/ui-toolbar-preview-refactor）

> 配套任务 14（真机测试 + 审计 + 修复循环）的执行清单。所有用例须在本地 360Chromex（扩展）与 Tauri EXE 两种形态下各跑一遍；扩展形态走 `chrome://extensions` 加载 `dist/`，需开启「允许访问文件网址」。

## 1. 范围与目标

覆盖本分支 10 项需求改造的功能正确性与回归：

| 编号 | 改造点 | 所在页面 |
|------|--------|----------|
| F1 | 撤销 / 重做按钮（含快捷键） | 编辑页 + 对比页 |
| F2 | 高亮拆分为「编辑区语法高亮」「预览区代码着色」两个独立按钮 | 编辑页 |
| F3 | 设置类按钮收拢进「⚙ 设置」弹出菜单 | 编辑页 |
| F4 | 标题/列表按钮收拢进「标题 / 列表」弹出菜单 | 编辑页 |
| F5 | Mermaid 预览渲染修复（空框） | 编辑页 |
| F6 | 行内 `== 高亮 ==` 与 GitHub 提示框 `> [!NOTE]`/`> [!WARNING]` 渲染修复 | 编辑页 |
| F7 | 「同步」按钮图标统一为锁链（与对比页一致） | 编辑页 |
| F8 | 对比页按钮顺序调整 | 对比页 |
| F9 | 对比页取消主区冗余「拖拽图片」栏，图片插入统一 | 对比页 |
| F10 | 文档（README + 示例说明书功能总表） | 文档 |

目标：10 项功能逐项可复现通过；既有功能（菜单关闭、工具栏溢出滚动、各原有按钮）无回归；控制台无报错。

## 2. 环境准备

1. `git` 工作区位于 `feat/ui-toolbar-preview-refactor`，改动**未提交**。
2. 本地构建：`npm run build` → 扩展卡片「重新加载」→ 关旧标签开新页。
3. 真机：360Chromex（路径 `D:\Tools\360Chrome\360chromex.exe`），Playwright 指定 `executablePath` 并复用登录态；首次运行前确认无未保存内容（读 `.cm-content` 字符数 + 预览）。
4. 准备测试样本：`demo.md`（含 Mermaid 块、`== 高亮 ==`、`> [!NOTE]`、`> [!WARNING]`、多级标题、有序/无序列表）；对比样本 `a.md`/`b.md`（含差异与一处整段搬家）。

## 4. 详细用例

### TC-E01 撤销 / 重做（编辑页）
- **前置**：打开 `demo.md`。
- **步骤**：
  1. 在编辑区输入一行文字 `AAA`。
  2. 点工具栏「↶ 撤销」按钮 → 观察文字消失。
  3. 点工具栏「↷ 重做」按钮 → 观察文字恢复。
  4. 重新输入 `BBB`，按 `Ctrl+Z` → 消失；按 `Ctrl+Y`（及 `Ctrl+Shift+Z`）→ 恢复。
- **预期**：按钮与快捷键行为一致，作用于当前编辑区历史栈。
- **通过判据**：4 种操作（按钮撤销/重做、Ctrl+Z、Ctrl+Y/Ctrl+Shift+Z）均生效，且按钮 tooltip 显示对应快捷键。

### TC-E02 高亮拆分为两个独立按钮（编辑页）
- **前置**：打开 `demo.md`。
- **步骤**：
  1. 点「⚙ 设置」→「编辑区语法高亮」→ 切换不同配色，观察编辑区 Markdown 语法着色变化。
  2. 点「⚙ 设置」→「预览区代码着色」→ 切换不同配色，观察预览区代码块着色变化。
  3. 验证两者互不影响（编辑区配色不变时预览区可独立切换）。
- **预期**：两个入口独立、与主题正交、各自持久化。
- **通过判据**：两组配色可独立选择并分别生效；刷新后各自保持。

### TC-E03 设置菜单展开 / 收起与互斥（编辑页）
- **前置**：打开任意文档。
- **步骤**：
  1. 点「⚙ 设置」→ 菜单展开，可见视图模式/外观/高亮方案/自动保持/显示设置/增强/其他各分区。
  2. 点菜单外部空白处 → 菜单收起。
  3. 再次展开「⚙ 设置」，再点「标题 / 列表」菜单 → 「⚙ 设置」应自动收起（互斥）。
  4. 展开任一菜单后按 `Esc` → 收起。
  5. 展开菜单后改变窗口尺寸 → 收起。
- **预期**：两个工具栏菜单互斥展开；外部点击 / Esc / resize 均关闭。
- **通过判据**：以上 5 步行为全部符合；菜单内各项 tooltip 正常。

### TC-E04 标题 / 列表菜单（编辑页）
- **前置**：打开空文档。
- **步骤**：
  1. 点「标题 / 列表」→ 菜单展开，含 H1/H2/H3/有序列表/无序列表。
  2. 在空行点 H1 → 行首出现 `# `；点 H2 → `## `；点 H3 → `### `。
  3. 点有序列表 → `1. `；点无序列表 → `- `。
- **预期**：原独立按钮已收拢，菜单项功能等价。
- **通过判据**：5 个菜单项均能正确插入对应 Markdown 语法。

### TC-E05 Mermaid 渲染（编辑页）
- **前置**：打开含 ```` ```mermaid ```` 代码块的文档。
- **步骤**：
  1. 预览区观察 Mermaid 图。
  2. 检查图中节点标签文字是否可见（非空框）。
- **预期**：图完整渲染，节点标签（foreignObject 内文字）不丢失。
- **通过判据**：Mermaid 图非空框，标签文字清晰可读；控制台无 DOMPurify 报错。

### TC-E06 行内 `== 高亮 ==` 与提示框（编辑页）
- **前置**：打开含 `== 高亮 ==`（含内侧空格 `== 高亮 ==`）、`> [!NOTE]`、`> [!WARNING]` 的文档。
- **步骤**：
  1. 预览区观察 `== 高亮 ==` → 应渲染为黄色高亮（`<mark>`）。
  2. 观察 `> [!NOTE]` / `> [!WARNING]` → 应渲染为带标题的提示框卡片。
  3. 检查提示框正文是否**只出现一次**（无内容重复）。
- **预期**：`== 高亮 ==`（含内侧空格）正常高亮；提示框正确渲染且内容不重复。
- **通过判据**：三项均符合；提示框正文无「这是备注这是备注」式重复。

### TC-E07 同步锁链图标（编辑页）
- **前置**：打开任意文档。
- **步骤**：
  1. 观察工具栏「同步」按钮图标 → 应为锁链（链接）形状，不再为双弯箭头。
  2. 开启同步 → 编辑区滚动时预览区联动。
- **预期**：图标与对比页一致；同步功能正常。
- **通过判据**：图标为锁链；联动滚动生效。

### TC-E08 编辑页工具栏回归
- **前置**：打开文档。
- **步骤**：
  1. 验证原有按钮仍可点：打开/保存/新建/加粗/斜体/引用/代码块/链接/表格/图片/查找/大纲/任务/快照/视图模式(⊞)/对比。
  2. 窄窗口下观察工具栏是否出现 `‹`/`›` 滚动按钮，所有按钮可达。
- **预期**：重构未破坏既有按钮与溢出滚动。
- **通过判据**：所有列出的按钮可用；窄窗按钮可达。

### TC-C01 撤销 / 重做（对比页）
- **前置**：打开 `a.md`/`b.md` 对比。
- **步骤**：
  1. 在某一栏（如 Yours）编辑文字。
  2. 点对比页「↶ 撤销」→ 该栏撤销；点「↷ 重做」→ 恢复。
  3. 切换活动栏到另一栏，确认撤销只作用于当前活动栏。
- **预期**：按钮作用于当前活动栏（`getActivePane` 决定）。
- **通过判据**：撤销/重做仅影响活动栏，不影响另一栏。

### TC-C02 对比页按钮顺序（对比页）
- **前置**：打开对比页。
- **步骤**：按工具栏从左到右核对顺序：
  1. 撤销 / 重做
  2. 三栏切换
  3. 选择文件 / 保存 / 滚动同步
  4. 差异导航（细线）
  5. 大纲
  6. 折叠未改
  7. 上一块 / 下一块
  8. 插入图片
- **预期**：顺序为「三栏 → 选择文件/保存/滚动同步 → 差异 → 大纲 → 折叠未改 → 上一块」，与重构要求一致。
- **通过判据**：顺序逐项吻合；各按钮可点。

### TC-C03 对比页插入图片 / 拖拽栏取消（对比页）
- **前置**：打开对比页。
- **步骤**：
  1. 确认主区**不再有**独立的「拖拽图片到此处」栏（原 `#compareImageDrop`）。
  2. 点「插入图片」按钮 → 选图片 → 插入到当前活动栏光标处，生成 `![name](data:image/...)`。
  3. 将图片文件直接拖入页面 → 应插入到活动栏光标处（整页拖放），且不与 MergeView 选区拖拽冲突。
- **预期**：图片插入统一为「按钮 + 整页拖放」，无冗余拖拽栏。
- **通过判据**：2、3 均成功插入；主区无独立拖拽栏残留。

### TC-R01 菜单关闭逻辑回归（双页）
- **步骤**：分别在各页验证「⚙ 设置」「标题 / 列表」菜单：外部点击关闭、Esc 关闭、resize 关闭、两菜单互斥。
- **通过判据**：双页行为一致且无残留展开。

### TC-R02 控制台稳定性（双页）
- **步骤**：执行上述用例过程中，监听 `console` 与 `pageerror`。
- **通过判据**：无未捕获异常；无 DOMPurify / Mermaid / CodeMirror 红色报错。
